# Clean Match Schedule

A clean, personal fixture table for the 2026 World Cup.

Hosted at <https://ono.github.io/clean-match-schedule/>.

I wanted a simple, readable schedule for myself, but feel free to copy it for your own use.

## Features

- Print-friendly fixture table.
- Match times shown in BST.
- Japan and England games highlighted.
- Games near the current time are highlighted automatically.
